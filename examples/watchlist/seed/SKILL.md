# Market Watchlist

For a security-analysis request, select an analysis mode for the instrument.
Normal mode retrieves news through the news service; fast mode bypasses news retrieval.
For an alert-check request, start by loading the saved watchlist and its alert conditions from local storage.
Then check the stored conditions against current market observations using the monitoring tool to produce an alert result.
Report the alert result.
The alert path is load, check, then report.
